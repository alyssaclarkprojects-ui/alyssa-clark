Pre-Publication Citation Review

Strategy Consultancy · 2026

Overview

Conducted a pre-publication citation review for a strategy consultancy's thought leadership report on strategic planning and somatic regulation. The review verified that each source was reputable, accurately supported its claim, and was cited appropriately, and strengthened the report with additional supporting references.

Context

The client wanted an external review of the report's sources before publication, delivered on a one-week turnaround.

Approach

  • Reviewed each existing reference against the passage it supports
  • Checked each source's credibility and confirmed it accurately supported the associated claim
  • Reviewed citations for appropriate and ethical attribution
  • Identified additional claims that would benefit from a citation and sourced supporting references
  • Marked the exact placement of each superscript citation and made the edits directly in the report documents
  • Organized all verified references into a final reference list

Outcomes

  • Verified, publication-ready reference list
  • Citations placed and edited throughout the report
  • New citations and references that strengthened the report's evidence base
