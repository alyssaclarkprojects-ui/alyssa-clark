Strategy Measurement

Statewide Data Strategy

Utah's Promise · May–December 2026

Overview

Designed a statewide data strategy and operating model to position Utah's Promise (UP) as a data intermediary supporting Promise Communities statewide. The engagement spans strategy, governance, reporting, technical assistance, and data culture across 30+ deliverables, and was built to complement UP's internal data team.

The Problem

As data sharing expanded across communities and state systems, UP needed shared standards, clear roles, and practical tools. This project aimed to support UP in making community data comparable and useful, both locally and at the statewide level.

Approach

  • Defined UP's value proposition as a data intermediary, its core functions and operating models, and a roles and responsibilities matrix spanning UP, local backbone teams, and partners
  • Built a governance model with a multi-tier data sharing structure, a data ethics code, shared definitions, tiered required and optional indicators, and submission protocols
  • Drafted guidance on data sharing agreements and suggested language for funding and partnership contracts
  • Designed a reporting system including an annual community impact report template, a statewide reporting framework for funders, state partners, and legislators, and a cross-sector indicator set
  • Developed a Data Use Toolkit covering bright-spot analysis, growth versus proficiency metrics, root cause analysis of disparities, and aligned-contribution storytelling
  • Created data culture and leadership tools, including light-touch guidance on using AI in insight and storytelling

Outcomes

  • Statewide data strategy and operating model
  • Data governance and standardization framework
  • Reporting templates for community and statewide audiences
  • Data Use Toolkit, public data access guides, and training materials
  • A synthesis document integrating the strategy, operating model, and tools for internal use and for positioning with funders and state agencies
